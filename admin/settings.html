ระบบ

สถานะการเชื่อมต่อข้อมูลของเว็บไซต์นี้

โหมดข้อมูลปัจจุบัน
-

ค่า dataMode ใน config.js
-

วิธีเปลี่ยนโหมดข้อมูล

แก้ค่า dataMode ในไฟล์ assets/js/config.js:

  • 'auto' ใช้ API ก่อน หากเชื่อมต่อฐานข้อมูลไม่ได้จะสลับไปใช้ข้อมูลตัวอย่างอัตโนมัติ
  • 'api' ใช้ฐานข้อมูลจริงเท่านั้น (แนะนำสำหรับเว็บไซต์ที่เปิดใช้งานจริง) หากเชื่อมต่อไม่ได้จะแสดงหน้าระบบไม่พร้อมให้บริการ
  • 'mock' ใช้ข้อมูลตัวอย่างในเบราว์เซอร์เท่านั้น ไม่เรียก API

รีเซ็ตข้อมูลตัวอย่าง

คืนค่าข้อมูลตัวอย่างทั้งหมด (การจอง ลูกค้า ล็อกเกอร์ ราคา การตั้งค่า) กลับเป็นค่าเริ่มต้น ใช้ได้เฉพาะเมื่ออยู่ในโหมดข้อมูลตัวอย่าง
